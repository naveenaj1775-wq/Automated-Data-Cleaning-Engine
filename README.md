\# Automated Data Cleaning Engine



\## Project Overview

The Automated Data Cleaning Engine is a Python-based web application developed using Streamlit. It helps users upload datasets, identify data quality issues, clean data and visualize useful insights.



\## Features

\- Upload CSV and Excel files.

\- Preview uploaded datasets.

\- Identify missing values.

\- Detect and remove duplicate records.

\- Handle missing values using different methods.

\- Perform data quality analysis.

\- Generate interactive data visualizations.

\- Download cleaned datasets in CSV and Excel formats.

\- Generate cleaning summaries and activity logs.



\## Data Visualizations

1\. Monthly Sales Trend

2\. Top 10 Countries by Revenue

3\. Top 10 Products by Revenue

4\. Sales vs Returns Analysis



\## Technologies Used

\- Python

\- Pandas

\- NumPy

\- Streamlit

\- OpenPyXL

\- XlsxWriter



\## Dataset

Online Retail Dataset – UCI Machine Learning Repository.



\## How to Run the Project



1\. Clone or download this repository.

2\. Install the required libraries:



```bash

pip install -r requirements.txt

```



3\. Run the application:



```bash

streamlit run app.py

```



4\. Open the local URL displayed in the terminal.



\## Project Objective

The objective is to simplify the data cleaning process and help users improve data quality through an interactive web application.
